Теоретическое введение

Модель SIR

  • Классическая эпидемиологическая модель
  • Популяция делится на три группы:
    • S (Susceptible) — восприимчивые
    • I (Infectious) — инфицированные
    • R (Recovered) — выздоровевшие

Система уравнений SIR

\[ \begin{cases} \dfrac{dS}{dt} = -\beta \dfrac{S I}{N} \\[1em] \dfrac{dI}{dt} = \beta \dfrac{S I}{N} - \gamma I \\[1em] \dfrac{dR}{dt} = \gamma I \end{cases} \]

где: - ( N = S + I + R ) — общая численность популяции - ( ) — коэффициент заражения - ( ) — коэффициент выздоровления
